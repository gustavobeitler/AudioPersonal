# Seguridad

No publique vulnerabilidades ni datos personales en una incidencia pública.

Hasta que el proyecto disponga de un canal privado específico, describa únicamente el área afectada y solicite contacto privado al mantenedor. No incluya grabaciones, catálogos musicales ni rutas personales.

Las versiones oficiales deberán generarse mediante el flujo automatizado del repositorio y, una vez aprobada la solicitud, firmarse mediante SignPath Foundation.
